# Клуб исторического фехтования МФТИ — сайт тренировок

Статический сайт на GitHub Pages. Бэкенд — две Google-таблицы.

## Что изменилось в этой ветке

Раньше все данные шли через Apps Script (`doGet` + JSONP + кэш), и каждая
страница ждала холодный старт скрипта — отсюда задержки в 10–30 секунд.

Теперь:

- **чтение** — напрямую из Google Sheets API v4 по публичному API-ключу;
- **запись комментария** — через крошечный Apps Script (`doPost`, ~140 строк):
  Sheets API не принимает анонимную запись даже в таблицу, открытую на запись;
- **запись тренировки** — Sheets API с OAuth-токеном админа;
- UUID заменены на буквы столбцов: ID тренировки — буква первого столбца её
  блока из 4 столбцов в таблице комментариев (`A`, `E`, `I`, `M`, `Q`, …).

### Сколько запросов уходит

| Действие | Запросов |
| --- | --- |
| Главная | 1 (0 при тёплом кэше в sessionStorage) |
| Страница тренировки | 2, параллельно (тренировка + её блок комментариев) |
| Запись комментария | 1 POST в Apps Script (без ожидания ответа) + перечитывание блока |
| Создание тренировки | 3 (проверка прав, номер блока, запись) |

Дополнительно: OpenLayers (~600 КБ) грузится лениво, уже после отрисовки
анонса, поэтому карта больше не задерживает контент.

## Структура

```
index.html            список тренировок
training.html         анонс + запись
create.html           форма админа

styles/               base → layout → components → pages
src/config.js         все настройки и ID
src/core/             dom, columns, format, auth, sheets
src/data/             trainings, comments  (доступ к таблицам)
src/features/         map, weather, announcement
src/views/            HTML-шаблоны
src/pages/            точки входа страниц
apps-script/Code.gs   только doPost для добавления комментария
```

## Схема таблиц

### Таблица тренировок (чтение публичное, запись — только у админов)

Лист `Trainings`, строка 1 — заголовки, данные с 2-й строки:

| A | B | C | D | E | F | G | H | I | J | K | L | M | N |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| key | createdAt | date | time | types (JSON) | comment | deployment | lat | lng | venue | lat | lng | quorum | weather |

Тренировка из блока N лежит в строке N+2 — благодаря этому её можно прочитать
одним запросом на одну строку.

### Таблица комментариев (чтение и запись публичные)

Лист `Comments`, **без строки заголовков**. Каждой тренировке принадлежат
4 столбца, блоки идут с шагом 4:

| Блок | Столбцы | ID тренировки |
| --- | --- | --- |
| 0 | A–D | `A` |
| 1 | E–H | `E` |
| 2 | I–L | `I` |
| 6 | Y–AB | `Y` |
| 7 | AC–AF | `AC` |

Внутри блока: имя, комментарий, голос, время отправки (ISO).

## Что нужно настроить перед публикацией

1. **API-ключ.** Google Cloud Console → Credentials → Create API key.
   Обязательно ограничьте его: *API restrictions* → только Google Sheets API,
   *Application restrictions* → HTTP referrers →
   `https://singulargamesstudio.github.io/kim/*`.
2. **Доступ к таблицам.** Обе таблицы — «Просмотр для всех, у кого есть
   ссылка»; таблица комментариев дополнительно «Редактирование для всех».
3. **Apps Script.** Замените содержимое проекта на `apps-script/Code.gs`,
   новый деплой: *Execute as* — Me, *Who has access* — Anyone.
4. **Заполните `src/config.js`:**
   - `SHEETS_API_KEY`
   - `COMMENTS.spreadsheetId`
   - `ADD_COMMENT_URL` (URL нового деплоя)
5. `npm run build` — проверяет, что все файлы на месте и в конфиге не осталось
   незаполненных `PASTE_…`.

Локальный запуск: `npm run dev` и `http://localhost:8000`
(нужен HTTP-сервер: ES-модули не работают по `file://`).
